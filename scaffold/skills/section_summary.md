# Per-section summary

For each section, write a 1-3 sentence summary (prefer 1 or 2 sentences;
use a third sentence only when strictly necessary to cover a numeric
threshold, exception, or cross-reference that would otherwise be
omitted) that:

- Captures the core requirement or definition.
- Preserves key legal terms, rule cross-references (e.g. "Rule 3110(b)",
  "SEA Rule 17a-4(b)"), dates, thresholds, and party names verbatim.
- Uses precise language appropriate for compliance professionals.

Do not pad. If the one-sentence form is faithful and complete, stop there.
