# Per-section summary

For each section, write exactly a 1-3 sentence summary that:

- Captures the core requirement or definition.
- Preserves key legal terms, rule cross-references (e.g. "Rule 3110(b)",
  "SEA Rule 17a-4(b)"), dates, thresholds, and party names verbatim.
- Uses precise language appropriate for compliance professionals.
