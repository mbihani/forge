# What to leave out

**Strip out**: amendment history, selected notices, version dates, navigation links, disclaimers, headers/footers, and page numbers from the summary content.

**Do NOT summarize supplementary material** unless it contains substantive rules (e.g., ".01 Foreign Registrations" should be included if it grants exemptions).
