# Features, Pricing & Support

This document covers the platform's API surface, integrations,
uptime SLAs, and support plans.

## API surface

The platform offers two API styles:

- **REST API** — available on all tiers (Free, Pro, Enterprise).
- **GraphQL API** — available on all tiers.

Both styles share the same rate limits defined in the service-tier
document. An API key is required for every request.

## SDKs

Official SDKs are provided for three languages:

- Python (3.9+)
- JavaScript / TypeScript (Node 18+)
- Go (1.21+)

SDKs are open-source and free to use on all tiers.

## Integrations

Out-of-the-box integrations are supported for four services:

- Slack
- Jira
- GitHub
- Datadog

All integrations are available on every tier, including Free.
Configuration is done from the workspace settings page.

## Uptime SLA

| Tier | Uptime SLA | Credits on breach |
| --- | --- | --- |
| Free | Best-effort (no guarantee) | None |
| Pro | 99.9% | 10% of monthly fee |
| Enterprise | 99.99% | 25% of monthly fee |

SLA credits are issued automatically when a monthly uptime falls
below the committed threshold.

## Support plans

- **Free** — community forum only; no email or phone support.
- **Pro** — email support with a 24-hour response time target.
- **Enterprise** — a dedicated Customer Success Manager (CSM),
  phone support, and a 1-hour response time target for critical
  issues.

Support is available Monday through Friday, 09:00–18:00 in the
workspace's selected region timezone, except Enterprise phone
support which is 24/7.
